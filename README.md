# Bobdyno

Laman-laman web untuk ekosistem Bob Dyno — Build · Inspire · Lead.

## Kandungan

| Fail | Keterangan |
| --- | --- |
| `index.html` | Laman pendaratan **Nadi** — catatan sunyi di bawah Bob Self Development. |
| `CNAME` | Domain tersuai GitHub Pages: `nadi.bobdyno.my`. |

Setiap laman ialah satu fail HTML yang lengkap sendiri: tiada langkah *build*,
tiada kebergantungan. Buka terus dalam pelayar, atau hidangkan sebagai fail statik.

## Hos

Laman ini dihidangkan oleh GitHub Pages di https://nadi.bobdyno.my

Domain tersuai ditetapkan oleh fail `CNAME` dalam branch yang diterbitkan
oleh Pages. Rekod DNS yang diperlukan di registrar `bobdyno.my`:

| Type | Name | Value |
| --- | --- | --- |
| CNAME | `nadi` | `dynopos.github.io` |

Selepas DNS merebak, hidupkan **Enforce HTTPS** dalam Settings → Pages.
